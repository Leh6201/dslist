# 📖 Sobre o projeto

O **DSList** é uma API REST desenvolvida em **Java** utilizando **Spring Boot**, criada com o objetivo de praticar conceitos de desenvolvimento Backend, arquitetura em camadas e construção de APIs.

A aplicação permite consultar uma lista de jogos e suas informações, utilizando uma estrutura organizada e seguindo boas práticas de desenvolvimento.

# ▶️ Como executar

Clone o projeto

```bash
git clone https://github.com/Leh6201/dslist.git
```

Entre na pasta

```bash
cd dslist
```

Execute utilizando Maven

```bash
./mvnw spring-boot:run
```

ou

```bash
mvn spring-boot:run
```

A aplicação ficará disponível em:

```
http://localhost:8080
```
